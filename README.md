# TASKLY – College Task Manager

TASKLY adalah aplikasi sederhana untuk membantu mahasiswa mengelola tugas kuliah.

## Fitur
- Menambahkan tugas kuliah
- Mengedit tugas
- Menghapus tugas
- Mengubah status tugas
- Memfilter tugas
- Menyimpan data menggunakan Local Storage

## Teknologi
- TypeScript
- Vite
- HTML
- CSS
- npm
- Git dan GitHub

## Cara Menjalankan
1. Clone repository.
2. Jalankan npm install.
3. Jalankan npm run dev.
4. Buka alamat localhost yang ditampilkan.

## Fitur Filter Tugas
TASKLY menyediakan fitur filter untuk melihat:
- Semua tugas
- Tugas yang belum selesai
- Tugas yang sudah selesai

## Catatan Project
TASKLY memudahkan mahasiswa mencatat dan menyelesaikan tugas perkuliahan.
